CLI, Terraform Provider & API Reference

Provision nodes declaratively using our OpenTofu/Terraform module or REST API.

CLI

nordctl cluster create --region waw-01 --nodes 3 --profile c2-nvme --k8s 1.31

Terraform

resource "nordcloud_pool" "prod" {
  region    = "fra-02"
  node_type = "epyc-32c-128g"
  count     = 4
}

cURL API

curl -H "Authorization: Bearer $NORD_TOKEN" https://api.nordcloud-sys.eu/v2/clusters
